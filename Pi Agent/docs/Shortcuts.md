https://pi.dev/docs/latest/usage  

## TUI commands

| Command             | Description                                                                    | 
| ---                 | ---                                                                            |
| /quit               | Close Pi Agent                                                                 |
| /resume             | Open the sessions manager (use it to delete sessions)                          |
| /model              | Open models selector                                                           |
| /recap              | Create a recap of the current session                                          |
| /compact            | Compact the current session                                                    |
| /new                | Start a new session                                                            |
| /fork               | Create a new session from a previous user message                              |
| /tree               | Jump to any point in the session and continue from there                       |
| /clone              |                                                                                |


** Nice to have **  
/? : Delete the current session and create anew one (or clear the current session completely)
